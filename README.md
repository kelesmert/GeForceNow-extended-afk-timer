# GeForce NOW Extended AFK Timer

A small Windows utility that keeps a visible GeForce NOW window active by periodically nudging it, then restoring it to its original position. It stops automatically after one hour.

This project is open source and unofficial. It is not affiliated with NVIDIA or GeForce NOW.

## Important

Since the last GFN update(2.0.86.124) it hasn't been possible to use the app, working on solutions.

## How It Works

- Finds a visible GeForce NOW window by process name or window title.
- Moves the matched window by 50 pixels.
- Waits 500 ms.
- Restores the window to its original position.
- Repeats every 10 seconds.
- Stops automatically after 60 minutes.

You can inspect the matching logic in [`gfn.cs`](./gfn.cs).

## Download

Download the latest `afk-timer-win-x64.exe` from the [GitHub Releases page](https://github.com/kelesmert/GeForceNow-extended-afk-timer/releases).

The release build is self-contained:

- No .NET installation is required.
- Windows 10/11 x64 is required.
- The executable is built from this repository using GitHub Actions.

## Usage

Download `afk-timer-win-x64.exe` and double-click it.

A console window will open and the timer will start automatically. Press `CTRL + C` or close the console window to stop it manually.

Optional: to list visible windows and see which one would be matched, run it from PowerShell:

```powershell
.\afk-timer-win-x64.exe --list-windows
```

## Trust And Safety

This repository publishes both the source code and the release executable.

Official release builds are generated by GitHub Actions using the workflow in [`release.yml`](./.github/workflows/release.yml). The executable is not built on a private local machine and uploaded manually. Release notes include the source commit and GitHub Actions run that produced the file.

Before running the executable, you can:

- Review the source code in [`gfn.cs`](./gfn.cs).
- Review the project settings in [`gfn.csproj`](./gfn.csproj).
- Review the GitHub Actions workflow in [`release.yml`](./.github/workflows/release.yml).
- Build the executable yourself from source.

The executable is currently not code-signed, so Windows SmartScreen may show an "unknown publisher" warning. That warning means Windows does not recognize the publisher; it does not prove the file is unsafe. If you do not trust the prebuilt executable, build it locally from the source code.

## Build From Source

Requirements for building:

- Windows
- .NET 8 SDK

Clone the repository, then publish a Windows x64 self-contained executable:

```powershell
git clone https://github.com/kelesmert/GeForceNow-extended-afk-timer.git
cd GeForceNow-extended-afk-timer
dotnet publish gfn.csproj -c Release -o publish
```

Output:

```text
publish\afk-timer.exe
```

The project is configured to publish a Windows x64 self-contained single-file executable, so the generated app does not require users to install .NET separately.
